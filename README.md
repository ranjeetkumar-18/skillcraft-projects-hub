# SkillCraft Technology – Unified Projects Hub

A sleek, responsive static site that brings together four interactive mini‑apps on a single page:

- **Projects Landing Page** – animated ambient glow, grid overlay, smooth navigation.
- **Precision Stopwatch** – start/stop, lap, reset with a modern UI.
- **AI‑assisted Tic‑Tac‑Toe** – human vs. simple AI with win detection & confetti animation.
- **LocalStorage To‑Do List** – add, edit, delete tasks that persist across sessions.

## Tech Stack
- **HTML5** – semantic markup + ARIA for accessibility.
- **Vanilla CSS** – custom dark‑theme, glass‑morphism effects, responsive layout, Google Fonts (Outfit, Plus Jakarta Sans, Space Grotesk).
- **Plain JavaScript** – no frameworks or build step required.

## Getting Started
1. Clone the repo.  
2. Open `index.html` in a browser **or** serve locally (`python -m http.server 8000`).  
3. (Optional) Deploy to GitHub Pages, Netlify, or Firebase Hosting – the site works out‑of‑the‑box.

## Why This Project?
- Demonstrates how multiple small web utilities can coexist on a single static page.  
- Serves as a starter template for rapid prototyping of modern, aesthetically‑rich web interfaces without any build tooling.
